第一步: 检查 AWS 账户
════════════════════════════════════════════════════════════════════════════

❓ 有 AWS 账户吗?

  ✅ 有 → 跳到「第二步」
  
  ❌ 没有 → 
      1. 访问 https://aws.amazon.com/
      2. 点击 "Create an AWS Account"
      3. 选择「创建免费账户」(Free Tier)
      4. 按照步骤完成注册
      5. 验证邮箱和电话
      6. 等待账户激活 (~5 分钟)
      7. 然后进行第二步

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第二步: 登录 AWS 控制台
════════════════════════════════════════════════════════════════════════════

1️⃣  打开浏览器 → 访问:
    https://console.aws.amazon.com/

2️⃣  选择「IAM 用户登录」(推荐，不要用根账户)

3️⃣  输入:
    ✓ 账户 ID (在邮件中或 AWS 文档中)
    ✓ IAM 用户名 (如果有)
    
    或使用「使用根用户邮箱登录」
    ✓ 邮箱: 你的 AWS 注册邮箱
    ✓ 密码: 你的 AWS 密码

4️⃣  点击「登录」

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第三步: 进入 IAM 控制台
════════════════════════════════════════════════════════════════════════════

您现在在 AWS 管理控制台中。

选项 A - 使用搜索 (最快):
  1️⃣  点击顶部的搜索框 (放大镜 🔍)
  2️⃣  输入: IAM
  3️⃣  点击搜索结果中的「IAM」

选项 B - 使用菜单:
  1️⃣  点击左上角「服务」按钮
  2️⃣  在搜索框输入「IAM」
  3️⃣  点击「IAM」

═══════════════════════════════════════════════════════════════════════════════

结果:
  您应该看到 IAM 控制台首页，左侧有菜单

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第四步: 创建 IAM 用户 (推荐，更安全)
════════════════════════════════════════════════════════════════════════════

为什么要创建 IAM 用户?
  ✓ 更安全 (不用根账户)
  ✓ 可以限制权限
  ✓ 可以单独禁用/删除
  ✓ 符合 AWS 最佳实践

步骤:

1️⃣  在 IAM 控制台，左侧菜单找到「用户」

2️⃣  点击「用户」

3️⃣  点击「创建用户」按钮 (右上角橙色按钮)

4️⃣  输入用户名:
    ✓ 建议: raft-quic-test
    ✓ 或: dev-raft
    ✓ 或: benchmark-user

5️⃣  勾选「提供用户访问 AWS 管理控制台」(可选)

6️⃣  点击「下一步」

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第五步: 分配权限
════════════════════════════════════════════════════════════════════════════

现在需要给用户 EC2 权限:

1️⃣  选择「直接附加策略」

2️⃣  搜索框输入: AmazonEC2FullAccess

3️⃣  在结果中找到「AmazonEC2FullAccess」

4️⃣  ✅ 勾选它

5️⃣  点击「下一步」

6️⃣  点击「创建用户」

✓ 用户创建成功！

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第六步: 生成访问密钥
════════════════════════════════════════════════════════════════════════════

现在为用户创建访问密钥:

1️⃣  在用户列表中，点击刚刚创建的用户名

2️⃣  选择「安全凭证」选项卡

3️⃣  向下滚动到「访问密钥」部分

4️⃣  点击「创建访问密钥」按钮

5️⃣  选择用途:
    ○ 本地代码开发 ← 选这个 (开发/测试用)
    ○ 其他

6️⃣  点击「下一步」

7️⃣  点击「创建访问密钥」

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第八步: 在本地配置凭据
════════════════════════════════════════════════════════════════════════════

打开终端，运行:

  $ aws configure

系统会提示:

  AWS Access Key ID [None]: 
    → 粘贴你的 Access Key ID

  AWS Secret Access Key [None]:
    → 粘贴你的 Secret Access Key

  Default region name [None]:
    → 输入: ap-east-1
    (或其他区域如: us-east-1, eu-west-1)

  Default output format [None]:
    → 输入: json

✓ 配置完成！

📋 故障排除
════════════════════════════════════════════════════════════════════════════

问题: "InvalidUserID.NotFound"
解决: 
  1. 检查用户名拼写
  2. 检查是否在正确的账户中
  3. 确认 IAM 权限

问题: "UnauthorizedOperation"
解决:
  1. 检查是否有 AmazonEC2FullAccess 权限
  2. 等待 1-2 分钟权限生效
  3. 再次运行命令

问题: "InvalidClientTokenId"
解决:
  1. 检查 Access Key 是否正确复制
  2. 重新运行 aws configure
  3. 创建新的访问密钥

问题: aws 命令无法找到
解决:
  1. 安装 AWS CLI: brew install awscli
  2. 验证: aws --version
