📋 凭据要求
════════════════════════════════════════════════════════════════════════════

必需:
  ✓ AWS 账户 (免费套餐或付费)
  ✓ IAM 用户 (具有 EC2 权限)
  ✓ Access Key ID (从 IAM 控制台获取)
  ✓ Secret Access Key (仅显示一次！妥善保管)
  ✓ 默认区域 (推荐: ap-east-1 香港)

获取凭据 (5 分钟):
  1. 登录 AWS 控制台: https://console.aws.amazon.com/
  2. 进入 IAM → Users → 你的用户名
  3. Security Credentials → Create access key
  4. 下载 .csv 文件
  5. 运行: aws configure

🚀 快速开始 (10 分钟)
════════════════════════════════════════════════════════════════════════════

1. 配置凭据 (一次性)
   $ aws configure
   输入: Access Key ID, Secret Access Key, ap-east-1, json

2. 验证配置
   $ aws sts get-caller-identity
   应显示你的 AWS 账户信息

3. 部署集群
   $ ./deploy/deploy.sh same-region
   等待 ~60 秒 EC2 启动...

4. 验证集群
   $ curl http://<node1_ip>:8001/status
   应返回 JSON 格式的 Raft 状态

5. 运行基准测试
   $ python3 scripts/benchmark.py \
       --host <node1_ip> \
       --ports 8001,8001,8001 \
       --writes 100 \
       --concurrency 1,4,8

6. 生成报告
   $ python3 scripts/visualize_svg.py
   $ python3 scripts/generate_report.py

7. 清理资源 (重要！)
   $ ./deploy/teardown.sh same-region

💡 提示和最佳实践
════════════════════════════════════════════════════════════════════════════

成本控制:
  • 使用 Free Tier (新账户 12 个月免费 750 小时)
  • 测试后立即销毁资源 (./deploy/teardown.sh)
  • 开发用同区域 (便宜, 延迟低)
  • 性能测试用跨区域 (压力测试)

安全:
  • 不要在代码中硬编码凭据
  • SSH 密钥妥善保管 (chmod 600)
  • 完成后删除访问密钥
  • 使用 IAM 角色 (生产环境)

故障排除:
  • 无法连接 SSH? 检查安全组规则
  • 权限错误? 检查 IAM 策略
  • Terraform 失败? `rm -rf .terraform*` 重试
  • 配额超限? 检查 AWS 配额或选择不同区域
